# B1 Kompass — будущие PRD и развитие

**Обновлено:** 1 ноября 2026 года. Это перечень направлений, а не обещание сроков и не созданные GitHub Issues будущих релизов.

Основная цель и общие решения описаны в [описании проекта](project-overview.md) и [полном документе решений](project-decisions.md). Деление — по пользовательским возможностям; отдельные PRD для frontend, backend и базы одного сценария не создаются. Политика безопасности и архитектурные правила общие для всех итераций.

Перед подготовкой следующего PRD, плана или задачи читать [архитектурные условия развития](architecture-evolution.md). Его реестр ARC-01–ARC-06 содержит текущие ограничения, момент расширения, необходимые проверки и привязку к направлениям ниже. Применимые пункты становятся архитектурным влиянием PRD, зависимостями плана и конкретными инвариантами/Verify задач; неприменимость объясняется. Это не добавляет все будущие функции в M1.

## Зафиксированные решения для будущих PRD

### 2. Режимы и таймеры

**Уточнено владельцем 2026-11-01:** разработка M2 идёт параллельно с ручной приёмкой M1. Найденные проблемы M1 исправляются отдельно; перед выпуском M2 проверяются базовый маршрут, настоящий материал и совместный сценарий. Непроверенные пункты отчёта M1 сохраняют свой фактический статус.

- Свободная тренировка без таймера остаётся доступной.
- Для полного экзамена нет управляемой паузы времени и пользовательских pause/seek/replay записи; после возврата позиция соответствует прошедшему экзаменационному времени. Когда срок Hören заканчивается, его ответы закрываются.
- В свободной тренировке и timed-блоке обычные контролы аудио остаются; пауза записи не останавливает таймер блока.
- Разрешено досрочно завершить весь экзамен после подтверждения числа неотвеченных заданий: учитываются сохранённые ответы, остальные — пропуски, итог из 45. Отдельного досрочного перехода из Hören в Lesen нет.
- Lesen начинается раньше по кнопке или автоматически через 60 секунд; переход не вычитается из его 45 минут.
- Сервер хранит абсолютные сроки; обновление страницы и открытие карточки слова не продлевают время.
- Повтор ошибок и аудиофрагментов отделяется от экзаменационного режима. Наличие автоматической разметки не предполагается заранее.

### 3–5. Библиотека и импорт

- Импорт/публикация — только администратору; обычным пользователям и Guest запрещены.
- Два входа — PDF и подготовленный JSON; единый проверяемый контракт. Модель извлекает материал, а не решает задания вместо источника ключа.
- Сначала надёжный текстовый слой PDF; OCR/модель подключаются при необходимости и после проверки доступности/качества. Безошибочное понимание любого PDF не обещается.
- Результат обработки — черновик; отсутствие или противоречие ключа блокирует публикацию, проблемные места требуют адресной проверки.
- Программа должна сокращать ручную работу; скриншот и перепечатывание каждого вопроса не являются выбранным процессом.
- Источники — оригинальные файлы и допустимые ссылки; для YouTube рассматривается видимый официальный iframe. Гарантия извлечения аудиодорожки из любого видео не даётся.
- Разметка соответствует группам: Teil 1–2 — отдельный вопрос, Teil 3 — пара, Teil 4 — общий набор a–f. Момент показа вопроса и начало речи не считаются одним и тем же без проверки.
- Готовые экзамены и рабочая очередь хранятся в облаке, обработка может выполняться локальным Docker-worker. Выключенный worker задерживает новый импорт, но не останавливает опубликованные тренировки.
- GPT Luna 6.1 — упомянутый кандидатом вариант подготовки через аккаунт; публичный API ID, цена, модальности и качество не подтверждены. Обязательная платная модель не выбрана.

### 6. Карточка слова

- Только одно слово, DE → EN / DE → RU по языку интерфейса; для нового Guest — English и DE → EN.
- Перевод, начальная форма, артикль/множественное число при достоверных данных, произношение и ссылки на другие словари.
- Направление интеграции: MyMemory/OpenThesaurus, ссылки DWDS/Duden; точные лимиты, пригодность источников и доступность грамматических данных проверяются до подключения.
- Перевод предложений и сохранение в личный словарь в этот PRD не входят.

### 7–8. Аккаунты и аналитика

- Email/пароль, подтверждение и восстановление через Supabase Auth — выбранное направление по аналогии с Cards. Это не означает готовую доставку писем и не требует Google-входа на первом шаге.
- Собственного домена пока нет; адрес сайта — Vercel. SMTP-провайдер не выбран. Публичная регистрация остаётся отключённой, пока внешние адреса не смогут получать письма.
- Пользователь видит свои попытки/результаты; администратор — сводку и предусмотренную детализацию всех пользователей. Роль назначается доверенно.
- Общий Guest остаётся тренировочным: гостевые показатели не выдаются за точный персональный прогресс; приблизительно считаются браузерные visitor_id, а не люди.

### 9–10. Устные модули

Bildbeschreibung и Gemeinsam etwas planen подтверждены как будущие направления. Пока не утверждены детальные упражнения, запись голоса, AI-собеседник, платный API или автоматическое оценивание речи. Их не следует добавлять в объём других PRD как уже согласованные требования.
