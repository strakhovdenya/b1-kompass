## Приватная подготовка и проверка

Публичный индекс имеет статус `INDEX_ONLY_NOT_CONTENT_SCHEMA` и **не является** ни `examContentSchema`, ни пригодным для `exam:validate` owner manifest. Нельзя подменять им настоящий `content`.

В рабочей переписке подготовлен **локальный ZIP для распаковки внутрь `private/`** с папкой `goethe/`, индексом, 45 ключами из издательской таблицы, контрольной матрицей и загрузчиком. **В Git этот архив, ключи, PDF и аудиофайлы не помещаются.**

На компьютере владельца после распаковки в `private/`:

1. В `private/goethe/` запустить `ONE_CLICK_DOWNLOAD_WINDOWS.cmd` (Windows) либо `bash ONE_CLICK_DOWNLOAD_MAC_LINUX.sh` (macOS/Linux). Загрузчик получает официальный PDF и ZIP, считает SHA-256, безопасно извлекает аудио. При нескольких записях склейки **не делает**; для текущего ARC-01 требуется одна цельная запись.
2. По первоисточнику создать точный `private/goethe/exams/exam-d/content.json` — 20 Hören, 25 Lesen, группы, полные немецкие варианты, тексты, примеры (не считать примеры).
3. Перепроверить оригинальное аудио, ключи и 45 вариантов. Запустить `node private/goethe/prepare_manifest.mjs` для получения приватного `manifest.json` только после заполнения content и единственной записи.
4. Из корня репозитория вызвать `npm run exam:validate -- private/goethe/exams/exam-d/manifest.json` и получить подтверждённый результат. Пока исходные данные не готовы, эту проверку **не считать пройденной**.
5. Публичный `exam:publish` — только после отдельного owner gate для D, проверки содержания/аудио и решения о правах. **Никаких обходов** существующего publisher, создания синтетического экзамена под этим названием или размещения ключа в `apps/web/public`.

См. [owner manifest v1](../../pilot-material.md), [deployment runbook](../../deployment.md), [ARC-01/02/03/06](../../architecture-evolution.md). Бесплатный доступ на сайте Goethe к PDF/ZIP не доказывает разрешение на размещение оригинала в стороннем приложении.
